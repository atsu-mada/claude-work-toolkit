# 2026-10-26 Modes chosen at start

- Two modes from the quality comparison: `eco` (configuration C, all Haiku) and `balanced` (B, Sonnet main
  with Haiku subagents). Names: short, model-neutral, and readable in Japanese UI text (エコ / バランス).
- Chosen at start by `code-survey <mode>`: models changed mid-session rebuild the prompt cache, and
  `CLAUDE_CODE_SUBAGENT_MODEL(_FORCE)` cannot change mid-session.
- No mode: the launcher asks in the terminal with no default. A SessionStart text asking Claude to confirm
  the mode was ignored by Haiku in a test, so a UserPromptSubmit hook holds the first prompt instead
  (interactive) or refuses the run (`-p`). Non-interactive detection uses `CLAUDE_CODE_ENTRYPOINT=sdk-*` or
  `CLAUDE_CODE_SESSION_ATTENDED=0`, seen on 2.1.310 but undocumented; unknown values count as interactive.
