# 2026-10-27 Rename to claude-work-toolkit

- The kit is meant to hold the tools used with Claude Code at work, not only the code survey (user request,
  2026-10-27). Name chosen by the user from three candidates: repository `claude-work-toolkit`, plugin and
  command `worktools` (skills are called `/worktools:<skill>`).
- Scope: visible names only (GitHub repository, marketplace, plugin, launcher command, directory
  `src/plugin/worktools`, docs). Kept on purpose: the `CODE_SURVEY_*` environment variables, the log and
  state folders (`~/.local/share/code-survey/`, `~/.cache/code-survey/`) and the `<settings>.code-survey.json`
  profile record, so existing logs and installs keep working.
- `install.py` recognises status lines written under either name, so rerunning it replaces the old entries.
- GitHub redirects the old repository URL. Decision records before this date keep the old names.
